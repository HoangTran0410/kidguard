### Which file? / Tải file nào?

| File | Install on / Cài lên | |
|---|---|---|
| **[kidguard.apk](https://github.com/HoangTran0410/kidguard/releases/latest/download/kidguard.apk)** | the **child's phone** / máy của con | parental control + kid launcher. Android 8+, any chip (ARM, x86_64) |
| **[kidguard-parent.apk](https://github.com/HoangTran0410/kidguard/releases/latest/download/kidguard-parent.apk)** | the **parent's phone** / máy bố mẹ | optional: alerts, SOS, requests. The web page works without it |
| [kidguard-home.apk](https://github.com/HoangTran0410/kidguard/releases/latest/download/kidguard-home.apk) | any phone / máy bất kỳ | only the kid launcher, no parental control |
| [kidguard-wear.apk](https://github.com/HoangTran0410/kidguard/releases/latest/download/kidguard-wear.apk) | a **Wear OS watch** only / chỉ đồng hồ Wear OS | "app not compatible" on a phone = wrong file |
| version.json | — | for the updater, don't install |
