Features

Enough for everyday use

⏱️

Daily time limit

One limit for all days or one per weekday. When time is up, apps are locked until midnight (except "Always allow" apps). Add 15 / 30 / 60 minutes when needed.

🙋

Child asks for more time

The child asks for 15 / 30 / 60 minutes with a reason. You tap Approve or Deny.

📦

Per-app control

Normal, N minutes per day, Blocked or Always allowed. New apps can stay locked until you approve them.

🌙

Bedtime and school hours

Locked time windows per day, even across midnight. A Pause now button: 30 minutes, 1 hour, until 6 am.

📍

Location

Locate now, 7-day history with stops on a map. Location can be forced on.

📊

Usage history

7 days of screen time and the most used apps.

👀

Screen view and control

Watch live, tap, swipe, type (Android 11+). The child always sees "A parent is watching the screen".

🧹

Clean-up New

Hide preinstalled manufacturer apps, see the heaviest apps, clear an app's data, all from the parent page. Hiding apps needs Device Owner.

🛡️

Hard to bypass

Blocks uninstall, force stop, factory reset, Safe Mode, clock changes, airplane mode. Restarts itself if killed. Also: DNS filter, lock screen, ring, reboot.

Remove everything at any time. Parent page, Settings, Release: every app is unlocked, every restriction is lifted, then uninstall KidGuard like a normal app.

Install

Pick the way that suits you

No computer, old phone? Use Basic mode. Want the strongest lock? Use Device Owner (the Android management role, like a company-managed phone).

Any Android 8+, no computer

🟡 Basic mode New

  1. Install the APK and open KidGuard.
  2. Tap Cài nhanh không cần máy tính (quick setup, no computer).
  3. Turn on each item of the list (device admin, accessibility, usage access, location, battery). Accounts can stay.

Weaker than Device Owner: blocked apps are sent back to the home screen instead of turning gray, and booting into Safe Mode stops the blocking. No DNS filter, no airplane mode / clock locks. You can upgrade to Device Owner later.

Android 11+, Wi-Fi

📱 Device Owner on the phone itself

  1. Remove all accounts on the child's phone (Google, Samsung...). Sign back in after setup and everything returns.
  2. Open KidGuard, tap Cài đầy đủ không cần máy tính (Android 11+) (full setup without a computer).
  3. Turn on Wireless debugging, choose Pair with code, type the 6 digits into KidGuard's notification. It does the rest.
New or factory-reset phone

🔳 Scan a QR code

  1. On the welcome screen tap 6 times on an empty spot.
  2. Scan the QR code.
  3. The phone downloads and installs KidGuard. Open it and finish the short checklist.
Chrome or Edge on a computer

🌐 Browser and USB cable

  1. Turn on USB debugging on the child's phone and plug it into the computer.
  2. Open the install page and press Connect. No adb needed.

Command line (macOS, Linux, Windows): scripts/setup.sh or scripts\setup.ps1 in the source repo.

After installing

The child's phone shows a 6-digit code and a QR code. On your phone (same Wi-Fi) scan the QR with the camera, or open http://<phone IP>:8770 and enter the code. Then go to Settings and set a parent PIN.

Xiaomi, Oppo, Vivo, Samsung

On the child's phone tap Cài đặt pin / tự khởi động (battery / autostart) and let KidGuard run in the background, otherwise the manufacturer may kill it.

Blocked by Google Play Protect ("App blocked to protect your device")? Play Protect blocks apps installed from a browser or file manager that use accessibility. Fix: Play Store, your avatar, Play Protect, the ⚙ icon, turn off Scan apps with Play Protect. Install KidGuard, finish setup, then turn it back on. The QR setup (Device Owner) is not affected, because the phone downloads the app itself.
Away from home

Remote control

At home the parent page connects directly over Wi-Fi. Away from home, pick Tailscale or a Cloudflare Worker.

Tailscale Recommended

A private network, instant responses, nothing to deploy.

  1. Make a free account at tailscale.com and generate an auth key (Reusable on, Ephemeral off).
  2. In the parent page (on home Wi-Fi): Settings, remote control via Tailscale, paste the key, tap Bật (On).
  3. Install Tailscale on your phone, sign in with the same account, open http://100.x.y.z:8770.

The child cannot turn off the VPN and only sees a key icon in the status bar.

Cloudflare Worker (advanced)

A small Worker on the free plan relays commands and state. Screen frames stay in memory only, never stored. Open it in any browser.

  1. Deploy the Worker (needs Node): cd worker && npm install && npx wrangler login && npx wrangler deploy
  2. In the parent page (on home Wi-Fi): Cài đặt, Nâng cao: relay Cloudflare Worker (Settings, advanced: relay), paste the Worker address, tap On.
  3. Open the link that appears on your phone.

iPhone / iPad

What if my child uses an iPhone?

Apple does not let third-party apps block other apps or see the screen, so there is no KidGuard for the child's side on iOS.

Your child uses an iPhone / iPad

Use Apple's free tools: Screen Time, Family Sharing and Find My for location.

You use an iPhone

That works: your child uses Android, you open the parent page in Safari. Away from home, install Tailscale from the App Store, or use the Worker.

FAQ

Good to know

Can the child uninstall KidGuard?

Not from Settings. A factory reset from the hardware keys (recovery mode) still works: KidGuard is then gone and the parent page shows "disconnected". In Basic mode, Safe Mode also stops the blocking, so use Device Owner when you can.

Does it work on older Android?

Android 8 and up. Live screen view and remote control need Android 11+, and so does the "on the phone itself" install. On Android 8 to 10 the child can force stop KidGuard (it starts again after a reboot).

Can the DNS filter cut off my child's Internet?

No. If the filter's server fails or the network blocks it for 90 seconds, KidGuard falls back to normal DNS for 30 minutes and the parent page says why.

Why do some apps show a black screen?

Apps that mark their screen as secure (banking and similar) appear black when viewed remotely.

Is any data sent anywhere?

Not by default: the parent page is served by your child's own phone. Only if you turn on the Cloudflare Worker do commands and state go through your own Worker. The Tailscale key does not go through the Worker.

Is it secure?

Each browser pairs once with a 6-digit code shown on the child's phone, and pairing more needs the parent PIN. The PIN is stored as a hash and never sent back to the page. Note: on home Wi-Fi the page runs over plain HTTP, so only use it on a network you trust.

Found a bug or have an idea?

Send it to GitHub Issues. How the parts talk to each other is described in docs/protocol.md.

Ready to try?

Download it, install on your child's phone, open the parent page. Not for you? Release and it is gone.
