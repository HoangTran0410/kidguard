# KidGuard decisions: setup-build

Index and the rule for adding lines: `README.md`.

## Decided
- 2026-11-13 UI text follows `docs/copy.md` (outcome first, one idea per sentence, short, glossary); owner: "must read every word" = rewrite.
- Design briefs must name 3-4 reference products (Pixel, Nova, iOS, Niagara) and give a "references -> what we took" table; each action has exactly one entry point; no status chip unless something is wrong; no stray section titles on canvas screens — owner rejected launcher mock v2 (11-07)
- UI/UX reviews must walk every action through idle/pending/active/stop/fail/screen-off/double-press/conflict on a running phone, not static screenshots; phone-reported state is source of truth (11-07, ux-review-must-walk-states)
- Agents in parallel work in separate git worktrees; one npm test at a time in relay/ (two at once = fake "Headers Timeout") (11-07)
- Kotlin source in feature folders (guard/ remote/ launcher/ setup/ ui/) but ONE package `dev.kidguard`: manifest components + Device Owner admin are bound to it (e08ce30). HomeActivity split into extension-function files, state stays in the activity (e397c07)
- docs/protocol.md is the contract; contract test checks Guard.kt / worker CMDS / protocol agree (1747923). A guard.kt folder move broke that test once (d1c75da)
- `kg.code` must go up every release (self-updater refuses equal versionCode); build.sh writes `.sha256` assets, self-update needs them (042d72a; v0.9.0 shipped stale hand-made ones)
- Site is static HTML+CSS, no JS (CSP script-src 'none' on most pages; only the llms "Hỏi AI" button allows 'self' script), deployed by `npx wrangler pages deploy website --project-name kid-guard --branch main` (direct upload); not tied to git
- Guide pages (website/guide.html + en/guide.html) replace GitHub README anchor links — user: links to nonexistent anchors not OK; stable section ids listed in website-guide report: install, install-phone/qr/usb/cli/basic, pair, parent-app, away, tailscale, relay, shared-relay, features, iphone, remove, faq (26e4309)
- Download links use `releases/latest/download/kidguard(-parent).apk` (no edit per release); version only as a hero chip (5ee5aae). Versioned names kidguard-<v>.apk also attached because Chrome saved "kidguard (1).apk" with no version (36f479a)
- APKs stay on GitHub releases: same-origin /dl/ hosting was tried and reverted (open-source provenance, one source to maintain) (9d75f23, reverted 7acef5e)
- English README only (README.vi.md dropped) (bf164b5). Site CSS cache-busted with a content hash (fb3d5ec)
- Release APK 7.4 -> 3.8 MB by dropping x86_64 and BouncyCastle PQC (747bc65)
- macOS bash 3.2: empty array with `set -u` broke build.sh (882cd92)
- Behind a TLS proxy: TRUSTSTORE=/path.jks scripts/build.sh
- CI flakes: wrangler dev gives 503 on a fresh Durable Object and sometimes hangs: rerun; per-IP rate limit trips fast CI runners -> tests retry 429 (9e6042a)
- Screenshots (2026-11-11): parent page from `scripts/shots/` (fake phones + invented fixtures, headless Chrome, vi+en); kid shots from the owner's POCO avoiding personal/finance apps (page 1 and the full drawer skipped, control-center background blurred). Site: `img/parent-*.webp` (vi), `img/parent-*-en.webp` (en), `img/kid-*.webp`; README uses `docs/img` (en). Run `scripts/stamp-site.sh` after replacing images.
- Website gallery: tap a shot = full-screen lightbox (`website/js/shots.js`, styles `.lb*` in site.css: CSP forbids inline); same image file, swipe/arrows/Esc, focus returns to the shot.
- Guide TOC (2026-11-11): scroll-spy `website/js/toc.js` (passed heading closest to the line, not TOC order: they once differed), Lucide icons as CSS masks from `website/img/ic/*.svg` (CSP has no inline), TOC order = page order.
- Auto re-grant (2026-11-11, owner: "auto luôn để rút ngắn step"): `setup/AutoGrant.kt` re-runs the setup's own grants (usage, notification listener, deviceidle, location fine+background, POST_NOTIFICATIONS) over self-adb when the checklist finds one missing; every 30 min, 6 h back-off when one won't take. Not done (unverified per OEM): MIUI `AUTO_START` appop, `ACCESS_RESTRICTED_SETTINGS`, `cmd role` HOME; ColorOS "permission monitoring" can't be switched by KidGuard.
- 2026-11-13 Keep app accounts when becoming Device Owner (measured, emulators with a test authenticator app): `pm disable-user --user 0 <pkg>` hides that app's accounts from AccountManager (its authenticator leaves RegisteredServicesCache; `dumpsys account` still lists the DB row, ignore it). API 33: set-device-owner then passes (flaky right after an earlier failed try). API 34: DPMS caches "has incompatible accounts" (`mHasIncompatibleAccounts`, recomputed at boot / LOGIN_ACCOUNTS_CHANGED, which shell may not send): disable, `sync`, reboot, then set-device-owner passes. `pm enable` after: account still there. suspend / per-user uninstall without reboot do not help. System authenticators (Google, Xiaomi, Samsung) still need removal. A first emulator run without the reboot wrongly concluded "impossible".
- 2026-11-13 Keep app accounts, implemented (setup.sh end to end on an API 34 AVD): `pm disable-user` is written to disk ~10 s later, so a reboot right after loses it (use >= 14 s + `sync`); after boot `set-device-owner` still says "accounts" for ~20-30 s, retry every 5 s. Always re-enable (EXIT trap / finally / apps-off file / localStorage / `Store.ownerPending`). Authenticator package must be non-system (`pm list packages -3`), else the parent removes the account. SelfSetup resumes from `Boot`/`Guard.onCreate`, needs the first unlock after boot.
- 2026-11-13 Setup audit fixes: checksum is fail-closed in setup.sh/ps1/install.html (`KG_ALLOW_UNVERIFIED=1` overrides in the scripts); setup.ps1 read `.sha256` via `.Content` (byte[] in Windows PowerShell 5.1, verified on Win10 laptop) and had a parse error (`":$cur:"` read as a scope, use `${cur}`); scripts keep the apps-off record for apps whose `pm enable` failed; install.html/qr.html are Vietnamese + English (table in the page, `kg.lang`, `?lang=`); SelfSetup resume treats a null shell as failure (`ss_conn_lost`). GitHub release downloads are not fetchable from a browser (no CORS), so an install page on the relay needs a worker `/kidguard.apk` proxy.

## Rejected / don't retry
- Same-origin APK hosting on the website (/dl/): reverted, back to GitHub release links (9d75f23)
- (2026-11-14) Agent token cost: `docs/flows.md` (~21k tokens whole) split into `docs/flows/<area>.md` (§ numbers kept); `docs/protocol.md` stays ONE file (contract test + setup scripts read it, one grep target) but a whole-file Read of it, `HomeActivity.kt`, `ui/install.html`, `ui/qr.html` is blocked by `.claude/hooks/big-read.py` (project `.claude/settings.json`): grep the heading, Read with offset/limit <= 200.
