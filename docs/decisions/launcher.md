# KidGuard decisions: launcher

Index and the rule for adding lines: `README.md`.

## Decided
- Launcher changes: build + install BOTH kid and home APKs; check resolved HOME (`cmd package resolve-activity -a android.intent.action.MAIN -c android.intent.category.HOME`) first; Poco's default home is dev.kidguard.home (11-09)
- Launcher perf pass 0.9.14 on the Oppo A5s (2026-11-11, release): cold home render 386 ms (+ a 2nd rebuild 118 ms ~1 s later when icons land); return home 0 % janky, no rebuild; pager 1.5 % p90 14; drawer 4 % p90 15; Hôm nay 1.7 % p90 14; idle 60 s = 1 frame. Over budget: long-press menu build 27-62 ms / first draw 61-119 (laps spread evenly: focus 2-5, head 6-13, rows 5-13, show 13-29 = CPU contention, no single hot spot); control center open 42-46 % janky p90 53: frame 1 = 37 ms build in the touch handler, frames 2-4 GPU 13-17 ms (first texture upload + full-screen scrim over home). Control center fixed the same day (see the CcKeep line).
- Control center smooth on the Oppo A5s (2026-11-11): 42-46 % janky p90 53 -> 23 % p90 19, open first draw 40-49 -> 7-10 ms, close 100 % -> 0 % janky. Causes, each measured: (1) building ~80 views + adding to the root per open = 37-40 ms frame -> built once, kept INVISIBLE in the root (`CcKeep`, prebuilt 2 s after onResume, rebuilt on key change); (2) phone caps (camera ids, AppOps, DND) = ~10 ms of binder per open -> checked off-thread after open, marks the panel stale; (3) close always set `window.attributes` (brightness reset) = `relayoutWindow` 13-19 ms (atrace) -> only when a drag changed it; (4) view alpha on the full-screen scrim + panel layer = offscreen redraw / 9-12 ms layer upload -> animate the scrim's ColorDrawable alpha, panel `hasOverlappingRendering=false`; (5) panel scale re-rasterized labels -> slide + fade only. Remaining 1-3 frames ~20 ms per open are GPU (home + dim + panel), the floor on this phone. Lesson: atrace (`atrace --async_start ... gfx view hwui`) finds window relayouts that gfxinfo only shows as sync time.
