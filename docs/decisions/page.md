- Map: one gesture helper (mapCtl) for location map, overview and place picker; tiles z clamped 3..18, .de tile fallback (b1110b8)
- Parent unlock speed: PIN hash hex via table (~11x faster), WebView warmed while typing (d1c75da)
- Icons: Lucide SVG/vector everywhere, no emoji in app, page or scripts (5d1853c, b604eb6)
- One QR library (ui/assets/qrcode.js) shared by parent page and qr.html (8f05f0c). TOTP QR drawn locally (4ce13f2)

- "Cần Device Owner" notes (2026-11-11, owner: Tailscale note next to a working switch): `needOwner()` only beside a control that is `.gated` / hidden in basic mode; where part works (Tailscale set up by hand + tsKeep, lock-screen contact -> Today Call button, launcher picked by hand) the note says which part needs the owner. Back: sub-screen -> Thêm -> Hôm nay -> list. The on-device page (LOCAL) has no list: no back arrow, no Danh sách / Cả nhà, `goList` is a no-op, Back at Hôm nay ends the session
- Map tile hosts live in 5 places: `TILES` (overview.js), CSP img-src (Http.kt, Proxy.kt, worker) AND the WebView request filters (AdminActivity `TILE_HOSTS`, parent MainActivity). 2026-11-10: the filters only had .org (blocked on the VN ISP), so the map failed in both apps
