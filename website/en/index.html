Which feature needs what

Before setup is finished the parent page still opens as a preview; features missing a permission are dimmed and say what they need.

FeatureNeeds
Preview the parent page, edit rulesNothing installed
Kid home screen, widgetsKidGuard set as the home app
App blocking, time limits, usage statsAccessibility + Usage access

Live screen view and controlAccessibility (Android 11+)

Without Device Owner KidGuard runs in basic mode: a locked app is sent back to the home screen. In the parent page, Settings has a Features & permissions list showing what the kid's phone still lacks.

Five ways to install

Install the APK and open it: the launcher, Dọn máy, the on-device parent page and the preview already work. Only Device Owner (A-D, strongest, optional) needs a phone with no accounts: remove them first, sign back in after. Step-by-step guide

  1. A

    On the phone itself Recommended

    Android 11+, Wi-Fi. Tap Cài đầy đủ không cần máy tính (Android 11+); it sets itself up over Wireless debugging.

  2. B

    Scan a QR code

    New or factory-reset phone: tap the welcome screen 6 times, scan the QR.

  3. C

    Computer and USB cable

    Open the installer page in Chrome or Edge, no adb needed.

  4. D

    Command line

    scripts/setup.sh or setup.ps1 on macOS, Linux, Windows.

  5. E

    Basic mode Weaker

    Any Android 8+, accounts stay: tap Cài nhanh không cần máy tính. Safe Mode stops the blocking.

Then scan the QR on the child's phone to open the parent page, and set a PIN. Xiaomi, Oppo, Vivo, Samsung: also tap Cài đặt pin / tự khởi động (battery / autostart).

Blocked by Play Protect? Pause Play Protect while installing.
  1. On the child's phone open Play Store → tap your avatar → Play Protect.
  2. Tap ⚙ → turn off Scan apps with Play Protect.
  3. Install and set up KidGuard.
  4. Turn Play Protect back on.

QR setup is not affected (the phone downloads the app itself).

Before you install

Can the child uninstall KidGuard?

Not from Settings. A factory reset from the hardware keys still works, and the parent page then shows disconnected.

Does it need root?

No. KidGuard uses Android's built-in Device Owner role, with no system modifications.

Does it work on older Android?

Android 8 and up. Live screen and the on-the-phone install need Android 11+.

Is any data sent anywhere?

Not by default: the parent page is served by the child's own phone over home Wi-Fi. No accounts, no ads, no analytics.

Does the child know they are being managed?

Yes, on purpose: the child can see their own rules and a log of what the parents changed. KidGuard is only for a parent managing their own minor child's phone.

Can the DNS filter cut off my child's Internet?

No. If the filter fails for 90 seconds, KidGuard falls back to normal DNS and the parent page says why.

Why do some apps show a black screen?

Apps that mark their screen as secure (banking and similar) appear black when viewed remotely.

Is it secure?

Each browser pairs with a 6-digit code on the child's phone, and pairing more needs the parent PIN. On home Wi-Fi the page is plain HTTP, so use it only on a network you trust.
