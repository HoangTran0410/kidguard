Install on the child's phone

There are five ways; pick one. Ways A to D make KidGuard the phone's Device Owner (the Android role a company uses for work phones): it can lock apps and can't be removed, no root needed. Way E skips this but is weaker.

Before ways A–D: Android only lets an app become Device Owner while the phone has no accounts (Google, Samsung, Xiaomi…).

On the child's phone open Settings → Accounts and remove them all. Sign back in after setup: everything comes back.

Keep apps signed in Beta Android only counts accounts of enabled apps. With way C (computer), instead of removing the Facebook, Messenger, OneDrive… accounts, disable those apps for a moment: adb shell pm disable-user --user 0 <package>, set up Device Owner, then turn them back on: adb shell pm enable <package>. The apps stay signed in. Google and Samsung accounts still have to be removed (system apps, not safe to disable). Which app owns which account: adb shell dumpsys account. Only partly tested (Galaxy A51, Android 13).

A. On the phone itself Recommended

Needs: Android 11+, Wi-Fi. No computer.

  1. Download the APK on the child's phone, install it and open KidGuard.
  2. Tap Full setup without a computer (Android 11+).
  3. Turn on Developer options: open About phone and tap Build number 7 times.
  4. In Developer options, turn on Wireless debugging and allow this Wi-Fi.
  5. Back in KidGuard, tap Show the code box in a notification. Then in Wireless debugging tap Pair device with pairing code.
  6. Pull down the notification shade, tap Enter pairing code and type the 6 digits shown.
  7. KidGuard does the rest, then turns Wireless debugging off again.

The code goes into a notification because the pairing dialog closes when you leave Settings. If the notification doesn't show, type the code in KidGuard itself.

B. Scan a QR code

Needs: a new or factory-reset phone with stock-like Android (Pixel, Samsung, Nokia…).

  1. Turn the child's phone on and stop at the welcome screen.
  2. Tap 6 times on an empty spot. The phone opens a QR scanner.
  3. Scan the setup QR code (open it on a computer or another phone).
  4. The phone downloads KidGuard over Wi-Fi and sets it up.
  5. Open KidGuard and finish the short checklist on screen.

Some skins drop the 6-tap screen (e.g. Oppo / Realme ColorOS on Android 8–9). Use way C there.

C. Computer and USB cable

Needs: a computer with Chrome or Edge, a USB cable. No adb to install. About 3 minutes.

  1. On the child's phone: remove every account (Settings → Accounts).
  2. Turn on Developer options: Settings → About phone, tap Build number 7 times.
  3. In Developer options, turn on USB debugging. Xiaomi / Redmi / POCO: also turn on USB debugging (Security settings) and Install via USB.
  4. Plug the phone into the computer and open the installer page in Chrome or Edge.
  5. Press the connect button and pick the phone in the dialog. On the phone tap Allow (tick “Always allow from this computer”).
  6. Press the install button. When it's done the page shows the address for the parent.

D. Command line

Needs: macOS, Linux or Windows, a USB cable.

  1. Prepare the child's phone as in way C, steps 1–3, and plug it in.
  2. Get the source on the computer (or just the setup.sh / setup.ps1 file).
  3. Run: 
    git clone https://github.com/HoangTran0410/kidguard && cd kidguard
scripts/setup.sh

# Windows
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
  4. The script downloads adb if it is missing, and the latest KidGuard release (SHA-256 checked) if it finds no APK. Add -y to skip the questions.
  5. It runs 8 steps: install the app, set Device Owner, grant usage access and secure-settings access, turn on accessibility, allow background running, open the app, print the parent's address.

E. Basic mode Weaker

Needs: any Android 8+. No computer, accounts can stay. For old phones with no QR screen and no computer or cable.

  1. Install the APK, open KidGuard, tap Quick setup, no computer needed.
  2. Turn on each item in order: device admin, accessibility, usage access, location (choose Allow all the time), notifications, battery.
  3. Each button opens the right system screen: turn the setting on, then press Back.

Why it is weaker: blocked apps are closed back to the home screen instead of greyed out.

  • Not available: family DNS, blocking app installs / USB debugging, locking airplane mode / location / clock, reboot, Tailscale.
  • A child who boots into Safe Mode or turns accessibility off stops the blocking. The parent page shows a red warning and the parent app notifies.

You can switch to Device Owner later with way A, C or D (accounts removed, like a fresh install). Rules and pairing are kept.

Open the parent page

After setup the child's phone shows a 6-digit code and a QR code.

  1. On your phone (same Wi-Fi as the child's), scan the QR with the camera. The page opens with the code filled in.
  2. Or open a browser at http://<child phone IP>:8770 and type the 6-digit code.
  3. Open the Settings tab and set a parent PIN. Without it the child's phone refuses to pair another browser.
  4. Sign back in to the accounts on the child's phone (if you removed them) and unplug the cable.
  5. Xiaomi, Oppo, Vivo, Samsung: on the child's phone tap Battery / autostart settings and let KidGuard run in the background.

Oppo / Realme / OnePlus (ColorOS): open Recents and pull the KidGuard card down to lock it (padlock icon). In Phone Manager allow KidGuard to autostart and run in the background. Swiping KidGuard away in Recents on ColorOS stops the app completely.

On home Wi-Fi the page is plain HTTP: use it only on networks you trust. Each browser pairs once with the 6-digit code; pairing more needs the parent PIN.

Parent app (Android)

The browser is enough to manage everything. The parent app adds notifications (SOS, more-time requests, accessibility turned off, lost connection) and shows the last data when the child's phone is offline.

  1. Download the parent app and install it on your phone.
  2. Open it and tap Add kid's phone.
  3. At home: type the address shown on the child's KidGuard screen, then the 6-digit code.
  4. Away from home: paste the relay link (like https://…/#c=…&k=…) from Settings, see Cloudflare Worker relay.
  5. Two kids or more: Overview shows every kid on one page.

A time request notification has +15 / +30 min and Decline buttons right on it. The app checks about every 15 minutes. For SOS in seconds (through the Worker and Firebase) you build the app yourself: see the README.

Parent on an iPhone: there is no app, the browser (Safari) is enough.

Tailscale Recommended

The child's phone installs Tailscale itself and joins your private network. No Cloudflare needed. Needs Device Owner (not in basic mode).

  1. On your phone: install the Tailscale app and sign in with Google / Apple / Microsoft. This also makes your free Tailscale account.
  2. Open the Keys page → Generate access token → Generate → copy it.
  3. At home (same Wi-Fi as the child's phone), open the parent page: Settings → Connection → Remote control via Tailscale.
  4. Paste the key into the tskey-api-… / tskey-auth-… box, optionally name the phone (e.g. kid-an), press Turn on.
  5. The child's phone downloads the official Tailscale app (SHA-256 checked), installs it silently, joins your network and hides the app. About a minute.
  6. The card shows Connected, an address like http://100.x.y.z:8770 and never expires.
  7. On your phone (with Tailscale on), open that address. Several kids: add each address with Add kid's phone.

Access token or auth key?

  • API access token (tskey-api-…), recommended: the child's phone makes its own one-off key and turns off Tailscale's 180-day key expiry for itself. The token is only used during setup, then dropped, never stored.
  • Auth key (tskey-auth-…): also works, but you turn off the expiry by hand once. Open the Machines page → the child's phone row → ⋯ → Disable key expiry. Otherwise Tailscale signs the phone out after 180 days. The parent page reminds you.

Good to know

  • Turning it on or changing the key only works at home. The key stays on the child's phone and never goes through the Worker.
  • The child can't turn the VPN off, change VPN settings or uninstall Tailscale. The safe-DNS filter keeps working.
  • To stop: press Turn off and remove Tailscale (or Remove controls). Then delete the phone on the Machines page, since an uninstalled app can't log itself out.

Your own relay (Cloudflare Worker)

A small Cloudflare Worker in your own free Cloudflare account relays commands, state and the live screen. Screen frames stay in the Worker's memory only, never stored. The parent's phone only needs a browser.

Needs: a computer with Node.js 18+. The Cloudflare account can be made for free at login.

  1. On the computer, run: 
    git clone https://github.com/HoangTran0410/kidguard && cd kidguard
scripts/relay.sh

# Windows
powershell -ExecutionPolicy Bypass -File scripts\relay.ps1
  2. The script does 3 steps: installs its tools (about a minute the first time), opens the Cloudflare login in your browser (if you're not logged in), then deploys.
  3. A new account may be asked to pick a workers.dev subdomain: answer it, it becomes part of the relay address.
  4. It prints the address: Relay ready: https://kidguard.<you>.workers.dev.
  5. At home, open the parent page: Settings → Connection → Advanced: your own relay (Cloudflare Worker). Paste the address, press Turn on.
  6. The page shows a remote-control link. Open it on your phone (keep it safe, don't share it), or paste it into the parent app.
  • Update: run the script again. Remove it from your account: scripts/relay.sh --delete (Windows: -Delete).
  • Free plan: 100,000 requests a day, one kid's phone uses about 4,300. Listen around doesn't work through the relay.

Shared relay (to try it)

Same as above, but paste https://kidguard.99-hoangtran.workers.dev: nothing to install. In exchange your child's state passes through the author's Cloudflare account, and the free daily quota is shared by everyone, so it can run out for the day. For daily use switch to Tailscale or your own relay.

Features

All in the current release, no paid tier.

Time

Daily limit
One number, or one per weekday. When time is up every app (except “Always allowed”) locks until midnight. +15 / +30 / +60 min for today.
Bedtime, schedules
Bedtime every day, plus windows on chosen days (school hours Mon–Fri); can cross midnight.
Heads-up before locking
The child gets a notification 5 min and 1 min before the limit, bedtime or a schedule locks the phone.
Pause now
30 min, 1 h, or until 6 am.
Ask for more time
15 / 30 / 60 min plus a reason; the parent approves or declines.
Chores
The parent lists chores (“Wash the dishes +20 min”); the child picks one when asking. Approve with a note if you like.
Unlock code
6 digits from Google Authenticator, no network on either phone. The child gets 15–120 min free of limits; each code works once.
Rule templates
School day, Weekend, Summer holiday, Exams, or save your own. Apply to one kid or several.

Apps

Per app
Normal, N minutes a day, Block, or Always allowed. Select many to change them at once.
App groups
One shared daily limit for a group (“Games”, “Social”) and/or hours when it may be used.
New apps
Optionally locked until a parent approves them.
Lighter phone
Hide the maker's preinstalled apps the child doesn't use, see the heaviest apps, clear an app's data. Needs Device Owner.
Updates itself
Once a day the child's phone checks GitHub releases, downloads the new APK and checks its SHA-256. Off or update now in Settings.

Location and safety

Location
Locate now, location forced on (the child can't turn it off), 7-day history on an OpenStreetMap map.
Zones
Home, School… with a radius: you're told when the child arrives or leaves.
SOS
A red button on the child's phone: the parent page shows the time and a fresh location; the parent app notifies.
See the screen
The child's screen live (Android 11+, ~3 fps). The child is told the parent is viewing.
Remote control
Tap, swipe, long press, Back / Home / Recents, type text.
Listen around
At most 10 min at a time, home Wi-Fi or Tailscale only. The child always knows: a beep, a notification, Android's mic dot.
Alerts
Arrived / left a zone, battery at 15 %, a new app installed, the clock changed.

Looking back

History
Screen time for 7 days, top apps per day, a weekly report per kid.
All kids
Overview: a card per kid, every kid's location on one map, 7 days side by side.
Child's rules
The child sees their own rules and a log of what the parents changed.
Languages
English and Vietnamese in the parent page and both apps.

Hard to break

Tamper-proof
Blocks uninstall, force stop, factory reset from Settings, Safe Mode, new users, changing the clock, airplane mode. A watchdog restarts it.
Optional
Family DNS filter (AdGuard / Cloudflare / CleanBrowsing), block installs, block USB debugging.
Commands
Lock the screen, ring, full-screen message, restart the phone.

Locked apps use Android's own mechanism: the icon turns grey and opening it says the parent paused it.

Child on an iPhone / iPad

There is no KidGuard for iOS: Apple doesn't let third-party apps see the screen, control the phone or lock other apps. Use what is built in and free:

  • Screen Time + Family Sharing: limits, downtime, app limits, adult-site filter, purchase approval, “ask for more time”, managed from the parent's iPhone.
  • Find My: the child's location.

Child on Android, parent on an iPhone: manage it from the iPhone's browser.

Remove KidGuard

  1. Parent page → Settings → Danger zone → Remove controls…
  2. Every app is unlocked and every restriction lifted. If Tailscale was on, it is removed too.
  3. Uninstall KidGuard like any app.

Troubleshooting

“App blocked to protect your device” (Play Protect)?

Play Protect blocks apps installed from a browser or file manager when they use accessibility. On the child's phone: Play Store → your avatar → Play Protect → ⚙ → turn off Scan apps with Play Protect. Install and set up KidGuard, then turn it back on. QR setup is not affected (the phone downloads the app itself).

No 6-tap spot on the welcome screen?

Some skins drop that screen (e.g. Oppo / Realme ColorOS on Android 8–9). Use the computer and USB cable.

Phone older than Android 11 can't set itself up?

Way A needs Android 11+. Use a computer (way C or D), factory reset and scan the QR, or use basic mode.

The parent page won't open?

Check the address on the child's KidGuard screen (default port 8770). Your phone must be on the same Wi-Fi, or the same Tailscale network, as the child's phone.

Can the DNS filter cut the Internet?

No. If the filter's host is refused, or the network has Internet but DNS-over-TLS is blocked for 90 seconds, KidGuard falls back to normal DNS for 30 minutes and the parent page says why.

Why do some apps show black when viewed remotely?

Apps that mark their screen secure (banking…) always show black.

Can the child remove it?

Not from Settings. A factory reset from the hardware keys (recovery) still works: KidGuard is gone and the parent page shows “disconnected”.

Limits on Android 8–10?

Live screen and remote control need Android 11+. On Android 8–10 the child can force stop KidGuard (it starts again on reboot).

Another bug or an idea?

Post it on GitHub Issues. Technical details: docs/protocol.md.
