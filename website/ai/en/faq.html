# Troubleshooting

“App blocked to protect your device” (Play Protect)?

Play Protect blocks apps installed from a browser or file manager when they use accessibility. On the child's phone: **Play Store** → your avatar → **Play Protect** → ⚙ → turn off **Scan apps with Play Protect**. Install and set up KidGuard, then turn it back on. QR setup is not affected (the phone downloads the app itself).

No 6-tap spot on the welcome screen?

Some skins drop that screen (e.g. Oppo / Realme ColorOS on Android 8–9). Use the [computer and USB cable](https://kidguard.asia/en/guide#install-usb).

Phone older than Android 11 can't set itself up?

Way A needs Android 11+. Use a computer ([way C](https://kidguard.asia/en/guide#install-usb) or [D](https://kidguard.asia/en/guide#install-cli)), factory reset and [scan the QR](https://kidguard.asia/en/guide#install-qr), or use [basic mode](https://kidguard.asia/en/guide#install-basic).

The parent page won't open?

Check the address on the child's KidGuard screen (default port 8770). Your phone must be on the same Wi-Fi, or the same Tailscale network, as the child's phone.

Can the DNS filter cut the Internet?

No. If the filter's host is refused, or the network has Internet but DNS-over-TLS is blocked for 90 seconds, KidGuard falls back to normal DNS for 30 minutes and the parent page says why.

Why do some apps show black when viewed remotely?

Apps that mark their screen secure (banking…) always show black.

Can the child remove it?

Not from Settings. A factory reset from the hardware keys (recovery) still works: KidGuard is gone and the parent page shows “disconnected”.

Limits on Android 8–10?

Live screen and remote control need Android 11+. On Android 8–10 the child can force stop KidGuard (it starts again on reboot).

Setup stops at usage access (Oppo / Realme / OnePlus)?

Turn on **Disable permission monitoring**, the last item in Developer options. Go back to KidGuard and setup carries on.

Child's phone is on Family Link: it says Developer options are on, but opening them lands on Settings?

Family Link blocks Developer options and debugging, so ways A, C and D can't run. In the parent's Family Link app: pick the child, open the device settings and allow Developer options. No such option? Stop supervising the child's account first, or use [basic mode](https://kidguard.asia/en/guide#install-basic).

Wireless debugging won't pair?

The child's phone needs Wi-Fi. No Developer options yet: the button in KidGuard opens **About phone**, tap Build number 7 times (Xiaomi/Poco: OS version). The pairing box closes when you leave Settings: type the 6 digits in the **Enter pairing code** notification. Each pairing has a new code.

Xiaomi / POCO: the update does not install by itself?

HyperOS always asks to confirm. When a parent taps update, the confirm screen opens on the child's phone at once: tap **Install**. Or tap the KidGuard notification. A Play Protect popup is normal: allow it.

“Too many wrong PINs, try again in N minutes”?

The child's phone locks PIN entry for up to 30 minutes. Wait it out, or use an Authenticator code.
